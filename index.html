How the student view opens

Season

The whole school slides when the weather turns. A season carries one offset in minutes, and every time you have already set moves with it — each staff punch window and the student cutoff — so nothing has to be retyped twice a year.

The offset moves the timetable, not the scan. A window of 08:00 to 11:00 reads as 08:30 to 11:30 once winter starts. A child punching at 08:40 is still recorded at 08:40. The gate machine reads this from the same settings, so there is nothing to change on the Worker.

Follow the calendar

Auto picks the season from today's date. Holding one season is for checking what it will look like — remember to put it back.

Seasons

Give the range without a year, so it repeats. A range may run past December — 1 Nov to 15 Feb is one winter. Minus shifts everything earlier, plus shifts it later.

A category that keeps its own hours

Security works the same clock all year. Put its own offset in the Season shift box on that category's card under Staff — 0 means the season never touches it. Left blank, the category follows the season.

Calendar

Which days count. Non-working days and holidays are left out of monthly percentages, and the Worker skips marking anyone absent on them.

Working days

The school default. A staff category that works differently — security on all seven days, for instance — gets its own days under Staff shifts.

Sandwich off

A holiday is unpaid only when the working day before it AND the working day after it are both absences.

Staff

Two punch windows per category. Both scanned is a full day, one is a half day, outside both is ignored. Tick "Duration mode" on a card to count by time-worked instead — useful for a category that doesn't cleanly split into two windows.

Duration mode

Applies to categories with it ticked above — time between first and last scan.

Before that time, one scan just means the day's still on — not yet a problem.

Fallback cutoff

Only used by a category with no windows set above — before it counts as arriving, at/after counts as leaving.

Night staff

Evening window = clock-in, next morning's window = clock-out (shown with "+1"). Add the employee IDs on a night shift — matched against whatever ID the device punches.

Devices

Every phone, tablet and desk PC that opens the register lists itself here, the one you're holding first. Rename any of them, choose what each opens on, hide staff categories a particular device shouldn't show, and turn off "Can edit" for a device that should only view attendance, not set anyone's day as Full/Half/Absent — all of it from whichever device you happen to have in hand.

All devices

Changes save as you make them, and reach the other devices the next time they open the register.

Password

Locks this settings popup. The register itself stays open to everyone — only changes are protected.

Settings password

Stored as a scrambled fingerprint, not as the password itself, so nobody can read it out of the database. Forgetting it means clearing settingsPassHash from app_settings in the Firebase console.

Backup

Keep a copy of this configuration, or carry it to another device without typing it all again.

Export

Downloads one file holding the cutoff times, calendar, staff shift rules, device list and the database address.

Import

Reads a file exported from here and replaces everything on this device with it. Nothing is merged, and nothing reaches the gate machine until you press Save & sync.
