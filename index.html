Attendance database

The same values as the Worker's RAW_FIREBASE_URL and RAW_FIREBASE_CODE variables. This is the only connection that reads and writes — settings you save here sync to app_settings.json, which the Worker reads on every scan.

Day timings

The cutoff splits a scan into a morning entry or an evening exit. The Worker reads these on every scan, so a change here changes how tomorrow's scans are filed.

Default cutoff

Scans before this time count as morning entry. At or after it, they count as an exit.

Different on certain weekdays

Half-day Saturdays, for example. One override per weekday — adding another replaces it.

Different on specific dates

Exam days, function days. Beats the weekday override for that date.

Calendar

Which days count. Non-working days and holidays are left out of monthly percentages, and the Worker skips marking anyone absent on them.

Working days

The school default. A staff category that works differently — security on all seven days, for instance — gets its own days under Staff shifts.

Sandwich off

A holiday or weekly off is paid on its own. It stops being paid when it is joined to an absence — a day off taken either side of it, or an absence sitting between two holidays.

Holidays

Fixed dates — festivals, breaks, a one-off closure.

Which staff categories — leave all unticked and it covers every category

Repeating holidays

Every second Saturday, for instance — applied to every month automatically.

Which staff categories — leave all unticked and it covers every category

Staff shifts

Each category keeps its own arrival and departure windows, because a driver starting at 4am and a teacher arriving at 8:30 can't share one dividing line. A scan inside the morning window is an arrival; inside the evening window it's a departure; outside both it falls back to the cutoff in Day timings.

Underneath, the same card decides how the day is judged: any scan counts as a full day, or the person must be seen in every shift window — miss one and it shows as half. Each category can also keep its own working days.

This device

Hide staff categories

Every device that opens the register lists itself here. Tick a category to hide it on that device — useful when a gate iPad should only show drivers. Rename this one above and it updates in the list.

Password

Locks this settings popup. The register itself stays open to everyone — only changes are protected.

Settings password

Stored as a scrambled fingerprint, not as the password itself, so nobody can read it out of the database. Forgetting it means clearing settingsPassHash from app_settings in the Firebase console.
